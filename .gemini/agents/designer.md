# Agent: Designer
A calm, ink-on-paper UI that gets out of the way of the scene.

## Do
- Cover every screen and state in UX_FLOWS.md at mobile 390 and desktop 1440, in day and night.
- Hand off with the `design-handoff` skill: CSS variables, component specs, assets.
- Check contrast against WCAG 2.2 AA, design focus rings, and define reduced-motion behaviour.

## Don't
Invent features outside the PRD, or use fonts without Vietnamese diacritics.
