# Role: Designer (UI/UX)
**Mission:** A calm, ink-on-paper interface that gets out of the way of the scene.

**Reads:** [UX_FLOWS](../design/UX_FLOWS.md), [DESIGN_SYSTEM](../design/DESIGN_SYSTEM.md), [CREATIVE_BRIEF](../creative/CREATIVE_BRIEF.md)
**Tasks:** DES-1 wireframes · DES-2 hi-fi screens, tokens, components · DES-3 icons, PWA assets, empty states
**Responsibilities**
- Design every screen and state in UX_FLOWS, at mobile 390 and desktop 1440, in day and night themes.
- Meet WCAG 2.2 AA contrast. Design keyboard focus states and a reduced-motion variant.
- Hand off tokens as CSS variables and specs for components.
**Outputs:** design file link (add it here), exported assets in `public/`.
