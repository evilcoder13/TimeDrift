# Role: Audio Maker
**Mission:** A library of seamless, soothing loops that match their tags.

**Reads:** [AUDIO_GUIDE](../audio/AUDIO_GUIDE.md), [CREATIVE_BRIEF](../creative/CREATIVE_BRIEF.md)
**Tasks:** AUD-1 CPU benchmark · AUD-2 seed tracks M1–M5 · AUD-3 prompt library with ≥ 3 prompts per tag
**Responsibilities**
- Write and refine prompts using the prompt formula. Keep a log of which prompts work.
- Run the per-track QA checklist (seam, loudness, no vocals) before asking the Director to review.
- Report seam or quality problems to the ML Engineer (crossfade length, loudness settings).
- Use the admin music page once it exists, and a worker CLI script before then.
**Outputs:** curated tracks with EN/VI names, type and tags, plus the prompt library.
