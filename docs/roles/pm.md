# Role: Product Manager
**Mission:** Ship the right MVP, on scope, in phases P0–P4.

**Reads:** [PRD](../product/PRD.md), [ROADMAP](../product/ROADMAP.md), [BACKLOG](../BACKLOG.md)
**Tasks:** PM-1 PRD, roadmap and backlog · PM-2 release go/no-go
**Responsibilities**
- Prioritise the backlog and move tasks to READY once their dependencies are met.
- Guard scope. Anything out of scope goes to "Later" in the roadmap.
- Run the weekly review: progress, risks (see PLAN §6), blockers.
- Track the success metrics after launch.
**Outputs:** an up-to-date backlog, phase exit reviews, a release decision.
